Sincronização na nuvem
Notas+ Cloud · FirebaseNão conectado Offline

A API Key web do Firebase não é uma senha. O acesso às notas continua protegido pelo login e pelas regras do Firestore.

A nuvem é opcional. Sem conexão, o app continua funcionando normalmente no aparelho.

Como preparar o Firebase
1. Crie um projeto Firebase e um banco Cloud Firestore.
2. Em Authentication, ative o provedor E-mail/Senha.
3. Em Configurações do projeto, copie a Web API Key e o Project ID para os campos acima.
4. Use regras que permitam a cada usuário acessar apenas a própria área: rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{userId}/{document=**} { allow read, write: if request.auth != null && request.auth.uid == userId; } } } As notas de texto e metadados são sincronizadas automaticamente. Anexos muito grandes permanecem no backup local para respeitar o limite de tamanho de documento do Firestore.
